# First Date Improv — tidy datasets

Generated by `transform-stats.mjs` (repo root) from
`src/assets/First Date Improv Stats_complete.xlsx`. Re-run with:

```
node transform-stats.mjs
```

Each dataset is emitted as both `.json` (for D3) and `.csv` (for eyeballing).
All player names are first names. Aggregates are **computed from raw data**, not
copied from the spreadsheet's pre-typed total rows (see "Known source issues").

## Datasets

### `scenes` — the backbone (1 row per player-per-scene-per-show)
From the `Shows` tab. Every other Shows-derived number can be computed from this.

| field | meaning |
|---|---|
| `showIndex` | show number as numbered in the sheet (may skip, e.g. 20, 25) |
| `showTitle` | show name |
| `sceneCode` | raw slot code: `1A 1B 1C D 2A 2B 2C E 3A…`, early shows used `4`/`5` for the group games |
| `sceneType` | `opening` (1A), `join-2person` (1B), `walk-on` (1C), `second-round` (2x), `third-round` (3x), `group-game` (D/E and bare numbers) |
| `round` | 1, 2, or 3 (group games D/`even#` → 1, E/`odd#` → 2) |
| `player` | first name |
| `weight` | participation weight in that scene: 1 = full, 0.5 = split, 0.25 = group-game share |

### `shows` — per-show meta (JSON has nested detail; CSV is compact)
`showIndex`, `showTitle`, `roster` (players in that show), `totals` (weight per
player), `initiations` (per player). 25 shows total.

### `initiations`, `walkons`, `fulljoins` — tidy player × scene-slot counts
From the matching tabs. Each: `{ player, slot, count }`. A `*.summary.json`
sidecar holds the original wide (player × all slots) view. `3s` = all third-round
scenes combined, as the source recorded them.

### `hosting` — chronological host / word-getter log
From `HostingWords`. `{ date (ISO), host, hostGuest (bool), hostNote, wordGetter }`.
Guest hosts (Andy, Heather) are flagged `hostGuest: true`. Co-hosted shows keep the
raw `"A + B"` string in `host`. `hosting.summary.json` has per-player `hosts`/`gets`.

### `players` — roster + rollups
`name`, `initials`, `showsAppeared`, `totalInitiations`, `totalWalkons`,
`totalFullJoins`, `hosts`, `gets`. The three "total" columns reconcile exactly with
the spreadsheet's own grand totals.

## Known source issues (left as-is in raw, corrected in computed totals)

The spreadsheet's per-show `TOTAL` rows were typed by hand, not formulas, and two
are arithmetically wrong. Our `scenes` data uses the real per-scene cells, so
computed totals differ from those two typed totals:

- **Rocketeer** — Jesa's column: cells sum to 5.75, typed TOTAL said 4.5.
- **Eyeball** — Jesa's column: cells sum to 7.25, typed TOTAL said 6.25.

The computed values are correct.
